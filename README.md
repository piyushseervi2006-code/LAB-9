# LAB 9 – Employee Information Using XML

## Project Overview
This project demonstrates how to read employee information from an XML file and display the data in a tabular format using HTML and JavaScript.

The application retrieves employee details from an external XML file using JavaScript's XMLHttpRequest and displays the information in an HTML table.

## Aim
To design a web page to read data from an XML file and display employee information in tabular format.

## Technologies Used
- HTML5
- XML (Extensible Markup Language)
- JavaScript
- CSS

## Features
- Reads employee information from an XML file.
- Loads data using XMLHttpRequest.
- Displays employee details in a table.
- Includes a button to load employee data.
- Shows Employee ID, Name, Department and Salary.

## How It Works
1. The user opens the Employee Information web page.
2. The user clicks the **Load Employee Data** button.
3. JavaScript sends a request to the XML file.
4. The XML file provides employee information.
5. JavaScript reads the employee records.
6. The details are displayed in an HTML table.

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open `index.html` using Live Server.
5. Click the **Load Employee Data** button.
6. View the employee information in the table.
